# 🧠 Smart Task Manager

**Smart Task Manager** is a simple and interactive web-based to-do list application built using **HTML, CSS, and JavaScript**. It allows users to add and organize daily tasks by priority and status, with a clean interface featuring a light/dark theme. :contentReference[oaicite:1]{index=1}

---

## 🛠️ Problem Statement

People often struggle to stay organized and remember daily tasks. Traditional notepads or sticky notes can be messy and easily lost. This project aims to provide a **digital task manager** that helps users keep track of tasks efficiently, categorize them by priority, and visually separate completed versus pending items. :contentReference[oaicite:2]{index=2}

---

## 🌟 Features Implemented

✔ Add new tasks with title  
✔ Tasks categorized by **priority** (High, Medium, Low)  
✔ Separate views for all tasks, pending tasks, and completed tasks  
✔ Simple, clean UI with dark/light mode toggle  
✔ Tasks sorted or filtered by priority and due status  
✔ Immediate validation message if the user tries to add an empty task title :contentReference[oaicite:3]{index=3}

## 🧠 DOM Concepts Used

This project uses key **DOM Manipulation** concepts:

- **Selecting elements** — `document.getElementById()` / `querySelector()`
- **Event listeners** — `addEventListener()` to detect button clicks
- **Creating elements dynamically** — `createElement()` for tasks
- **Updating classes** — add/remove CSS classes to change UI based on task status
- **Appending elements to the document** — `appendChild()` after creating tasks
- **Conditional UI updates** based on user interactions and state

## ⚠️ Known Limitations

❗ Currently, the app **does not save tasks between page refreshes** *(no local storage or database yet).*  
❗ You cannot **edit task names or due dates** once created (only add or mark complete).  
❗ No backend/API integration — it’s a fully front-end static app.  
❗ No search or sort by date feature yet.
